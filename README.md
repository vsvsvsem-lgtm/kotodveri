# Котодвери

Новогодний адвент с котиками: каждую неделю новая дверца и новая порода. За каждой дверцей ждёт что-то заМУРчательное!

Сайт состоит из одного файла `index.html`, сборка не нужна. Мурчание создаётся прямо в браузере, звуковых файлов нет.

## Как разместить на GitHub Pages

1. На github.com нажмите **New repository**, назовите его, например, `kotodveri`, сделайте публичным.
2. Загрузите в репозиторий файлы `index.html`, `.nojekyll` и `README.md` (**Add file → Upload files**).
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/kotodveri/`.

Прогресс (открытые дверцы) хранится в браузере посетителя. Котиковые факты лежат в массиве `FACTS` в `index.html`.
