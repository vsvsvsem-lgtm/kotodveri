# Котодвери

Новогодний адвент с котиками: каждую неделю новая дверца и новая порода. За каждой дверцей ждёт что-то заМУРчательное!

Сайт состоит из одного файла `index.html`, сборка не нужна. Мурчание создаётся прямо в браузере, звуковых файлов нет.

## Как разместить на GitHub Pages

1. На github.com нажмите **New repository**, назовите его, например, `kotodveri`, сделайте публичным.
2. Загрузите в репозиторий файлы `index.html`, `.nojekyll` и `README.md` (**Add file → Upload files**).
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/kotodveri/`.

Прогресс (открытые дверцы) хранится в браузере посетителя.

## Языки (RU / EN)

Переключатель RU / EN находится в правом верхнем углу. Выбранный язык хранится в `localStorage` (ключ `kd-lang`), по умолчанию — русский.
Все тексты лежат в `index.html`, в одном месте:

- `I` — словарь интерфейса (`I.ru`, `I.en`);
- `BX` — тексты пород (`BX.ru[i]`, `BX.en[i]`, порядок совпадает с массивом `B`): описание, размер и вес, продолжительность жизни, характер, активность, уход, совместимость, здоровье, интересный факт;
- `FT` — котиковые факты (`FT.ru`, `FT.en`, одинаковое количество и порядок).

Чтобы добавить язык, добавьте ключ в `I`, `BX` и `FT` и кнопку в `#lg`.

## Мурчание

Звук по-прежнему синтезируется в браузере (Web Audio API), файлов нет. Есть три варианта — «Спокойное», «Довольное», «Приветственное» (короткое, останавливается само); параметры лежат в объекте `PV`. Звук включается только по нажатию, плавно нарастает и затухает, повторное нажатие на кнопку останавливает его. Выбранный вариант хранится в `localStorage` (ключ `kd-pv`).
